## The entry

> The decision was already made, the email already said it, and this meeting is just us reading it out loud together for an hour — so go back to work.

## Why it kills the meeting

The line does the meeting's only job before the meeting starts: the decision
already exists, it already reached everyone by email, and the hour on the
calendar adds nothing but a live read-aloud of what was already written.
After this sentence, nobody can justify staying — the room is dismissed and
the hour is handed back.

## How to run

Requires Node 22 or later (Node runs the TypeScript directly):

```sh
node main.ts
```

The program writes the single sentence to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), after
checking it is one sentence of 1–200 characters.
